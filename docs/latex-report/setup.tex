\begin{abstract}
    This paper documents the systematic hardening of an existing Spring Boot microservice application using static analysis, mutation testing, and DevSecOps integration. The intervention successfully achieved 100\% code coverage and a 73\% performance gain by optimizing a critical algorithmic bottleneck via microbenchmarks. However, the study confirmed that rigorous formal specification (JML) is incompatible with modern, Lombok-heavy architectures due to bytecode generation conflicts. We conclude by defining a pragmatic, hybrid strategy for software dependability centered on a rigorous, security-aware CI/CD pipeline.
\end{abstract}
